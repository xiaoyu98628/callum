# Callum

Callum 面向通用任务 Agent 开发，目标是通过模型推理与工具调用完成任务，
支持多轮对话、多对话异步执行、上下文压缩和执行取消。

## 当前状态

项目处于重新构建阶段，下一步从模型接入开始。
当前入口为 `cmd/callum/main.go`，运行后输出 `hello world` 并退出，尚未接入模型。
Go 版本以 `go.mod` 为准，当前为 Go 1.27.3，暂无第三方依赖。

## 开发规划

以下为计划实现的能力：

1. **模型接入**：接入一个模型供应商，支持文本请求、流式输出、上下文取消和错误处理。
2. **普通对话**：管理多轮消息历史、组装模型上下文，支持多个对话异步执行和独立取消。
3. **Agent 与工具**：实现工具注册、参数与权限校验、工具执行，以及结果回传模型的执行循环。
4. **上下文压缩与恢复**：管理 Token 预算、历史摘要和压缩版本，逐步完善执行状态持久化与中断恢复。

第一阶段按职责引入以下模块：

| 规划目录 | 职责 |
| --- | --- |
| `internal/model` | 业务使用的模型接口、请求、响应、流式事件和错误类型 |
| `internal/provider/<供应商名称>` | 具体供应商的请求、认证、消息转换和流式响应解析 |
| `internal/config` | 模型接入所需配置及校验 |

普通对话、运行调度、工具和上下文管理模块随对应功能引入。
具体接口、供应商、参数和存储方案在实施时确定，按实际需求增加目录和依赖。
